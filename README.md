# H&A — لعبة الرسم والتخمين اللحظية

لعبة رسم وتخمين لشخصين تعمل عبر المتصفح في الوقت اللحظي (WebSockets) — أحدهما يرسم والآخر يخمن، ثم يتبادلان الأدوار.

## المميزات
- 🎨 راسم يختار كلمته من خيارين عشوائيين أو من كلمة مخصصة
- ⏱️ مؤقت 90 ثانية لكل جولة مع تنبيهات صوتية وبصرية
- 🏆 نظام نقاط للفائزين (المخمّن عند الصواب، الراسم عند انتهاء الوقت)
- 💬 شات تخمينات لحظي بأسماء اللاعبين
- 📩 رابط دعوة — الصديق يكتب اسمه فقط وينضم تلقائياً
- 🖌️ أدوات رسم: فرشاة، ممحاة حرة، ألوان، أحجام، تقريب/تنقّل (لمس وموس)
- 📱 يعمل كـ PWA — يُثبّت على شاشة الهاتف

## التشغيل محلياً
```bash
npm install
npm start
```
ثم افتح `http://localhost:3000`

## النشر السحابي (Render)
يوجد ملف `render.yaml` جاهز — اربط المستودع بـ Render واختر Web Service، وسيحصل تلقائياً على رابط عام ثابت مثل `https://hna-game.onrender.com`.

## التقنية
- Node.js + Express + Socket.io (خادم WebSockets)
- Canvas API مع مزامنة الرسم لحظياً (source-over / destination-out للممحاة)
- PWA: Service Worker (تخزين مؤقت) + Web App Manifest
